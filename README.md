# Exercise of the Week — Functional Core Fitness

Live page: https://functionalcorefitness.github.io/Exercise-of-the-week/exercise-of-the-week.html

A new exercise every Monday from Coach Omar Lima's YouTube library. The page picks the exercise from the date on its own; nobody has to update it each week.

## What's on the page
- This week's exercise with the video, description, muscles worked, benefits and coach tips
- ‹ › buttons, keyboard arrows or a swipe on the title to browse every exercise; **This Week** jumps back
- **All Exercises**: the full library with search
- Tap a muscle to see a detailed anatomy picture and every exercise that trains it
- Tap a benefit to see every exercise with that benefit
- **Share** button and shareable links, for example `exercise-of-the-week.html?ex=bird-dog`
- QR code to the YouTube video, for the studio iPad
- Google Analytics 4 (G-86LMLPZE5K) tracks visits, exercises viewed, video clicks, shares and joins

## Adding a new exercise
Open `exercise-of-the-week.html`, find `var exercises = [`, and add the new exercise **at the end of the list**. The schedule adjusts itself, so there is no offset number to change.

## Files
- `exercise-of-the-week.html`: the main page
- `join.html`: the sign-up page
- `index.html`: the exercise library page
- `anatomy/`: web-sized anatomy pictures used on the page
- `muscle-images/`: full-size originals of the anatomy pictures
